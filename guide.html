Start Guide

1. Install ASP.NET Core 10.0 Runtime

Install ASP.NET Core 10.0 Runtime (v10.0.11):

Download ASP.NET Core 10.0 Runtime

2. Deploy the Application

Open PowerShell as Administrator, navigate to the application folder, and run the deployment script:

./deploy.ps1
Note: Make sure you are inside the application folder before running the script.

3. Access the Application

After deployment, open your web browser and navigate to:

http://localhost

You should see the application running successfully.

4. Install the Windows Service Monitor App

Open PowerShell as Administrator, navigate to the application folder, and run:

./install-service.ps1

The Windows Service Monitor should now be installed and running.

5. Run the Application with Docker Engine

Open PowerShell as Administrator, navigate to the application folder, and run:

./deploy-docker.ps1

The application should now be running through Docker Engine.
