2. Missing Items (Gaps & Edge Cases)

Items identified that require attention to achieve unconditional 100% evaluation score:

GAP-01: Missing Universal Visual Studio Solution Format (.sln) Deliverables Gap

Finding: The solution is authored in CustomerManagement-Spike.slnx (Visual Studio 2022 v17.10+ preview XML format). Legacy IDEs (Visual Studio 2019/2022 RTM) or build runners without .slnx support fail to load the solution.

Remediation: Provide standard CustomerManagementSpike.sln alongside the modern .slnx.

GAP-02: Missing Candidate Deliverable Source Packager Script Deliverables Gap

Finding: The specification requires "Source: Packed as zip file" for email submission. While CI generates a zip of the web binaries, there was no automated script to package a sanitized copy of the complete repository (excluding bin/, obj/, .vs/, .git/).

Remediation: Implement package-submission.ps1 to generate the final candidate zip file.

GAP-03: CI Workflow Docker Hub Step Fails on Unconfigured Forks Pipeline Edge Case

Finding: In .github/workflows/ci.yml, the Docker Hub login and push steps execute on all non-PR runs without verifying if secrets.DOCKERHUB_USERNAME is populated. Evaluators running the pipeline on a fork will experience a failed build step.

Remediation: Add a condition: if: github.event_name != 'pull_request' && secrets.DOCKERHUB_USERNAME != ''.

GAP-04: IIS Dual Physical Path Conflict in deploy.ps1 Infrastructure Polish

Finding: Both the root site (CustomerSpike) and the child application (/app) point to the same physical folder (C:\inetpub\wwwroot\CustomerSpike\App), which can cause ASP.NET Core Module file lock contention on web.config.

Remediation: Separate the root landing folder (...\Root) from the child application folder (...\App).

Step 2: Add Candidate Submission Packager (package-submission.ps1)

# Creates sanitized candidate deliverable zip for email submission:
[CmdletBinding()]
param([string]$OutputFile = "CustomerManagement-Spike-Submission.zip")

$scriptDir = Split-Path -Parent $MyInvocation.MyCommand.Path
Write-Host "Cleaning build caches..." -ForegroundColor Cyan
Get-ChildItem -Path $scriptDir -Recurse -Include bin, obj, .vs, TestResults | Remove-Item -Recurse -Force -ErrorAction SilentlyContinue

$exclude = @(".git", ".vs", "TestResults", $OutputFile)
$files = Get-ChildItem -Path $scriptDir | Where-Object { $exclude -notcontains $_.Name }
Compress-Archive -Path $files.FullName -DestinationPath (Join-Path $scriptDir $OutputFile) -Force
Write-Host "[SUCCESS] Submission zip created: $OutputFile" -ForegroundColor Green
